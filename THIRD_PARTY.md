# Third-Party Dependencies

Dependencies are installed from package indexes and are not vendored in this repository. The direct dependencies currently declare permissive licenses:

| Package | Declared license family |
| --- | --- |
| NumPy | BSD-3-Clause |
| pandas | BSD-3-Clause |
| python-dotenv | BSD-3-Clause |
| Requests | Apache-2.0 |
| scikit-learn | BSD-3-Clause |
| SciPy | BSD-3-Clause |
| tabulate | MIT |
| AKShare | MIT |
| easyquotation | BSD |

Installed distributions include their own license files and transitive dependencies. Consumers should regenerate a software bill of materials for the exact versions used in deployment.
